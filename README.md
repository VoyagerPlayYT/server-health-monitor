## 🌟 Описание проекта

**Server & PC Health Monitor Dashboard** — это интерактивная веб-консоль системного администратора. Она разработана для непрерывного мониторинга аппаратного состояния физического оборудования или виртуальных машин без необходимости подключения по SSH или RDP.

### Ключевые возможности:
- 📊 **Потоковая передача телеметрии по WebSocket**: обновление данных каждую секунду без перезагрузки страниц и с минимальной нагрузкой на сеть.
- 📈 **Динамические графики (Chart.js)**: отслеживание трендов нагрузки процессора (CPU %), оперативной памяти (RAM %) и сетевого канала (RX/TX в КБ/с).
- ⚙️ **Поядерная детализация CPU**: наглядные индикаторы нагрузки для каждого физического и логического ядра.
- 💾 **Мониторинг всех накопителей и разделов**: емкость, занятый и свободный объем для всех дисков (SSD/HDD).
- 🔥 **Топ ресурсоемких процессов**: автоматическое выявление приложений, потребляющих больше всего процессора и памяти.
- ⏱ **Точный счетчик Uptime**: время непрерывной работы узла с момента последней перезагрузки.

## 🛠 Стек технологий

- **Backend**: Python 3.11+, FastAPI, Uvicorn, psutil (низкоуровневый опрос системных вызовов OS), WebSocket Protocol
- **Frontend**: HTML5, Tailwind CSS, Chart.js, Vanilla ES6 JavaScript с механизмом автоматического реконнекта сокета
- **Дизайн**: Футуристический темный Cyberpunk / Datacenter интерфейс со светящимися карточками метрик

## 🚀 Быстрый запуск

### Запуск в 1 клик (Windows):
Дважды щелкните по:
```bash
start.bat
```
*(Панель запустится и откроется в браузере по адресу `http://localhost:8002`)*.

### Запуск вручную:
```bash
pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 8002
```
Для мониторинга с телефона введите в мобильном браузере: `http://<IP_СЕРВЕРА>:8002`.

## 🖥 Зачем этому проекту нужен выделенный сервер 24/7?

Этот проект является фундаментальным ядром управления всей домашней IT-инфраструктурой:

1. **Непрерывный контроль 24/7 без сна**:
   - Обычный ПК уходит в спящий режим или выключается на ночь, прерывая сбор метрик. Выделенный сервер работает без перерывов, накапливая историю и графики за недели и месяцы.
2. **Раннее предупреждение аппаратных аварий и перегрева**:
   - Сервер контролирует температуру процессора, состояние SMART жестких дисков и заполненность хранилищ. При критических скачках нагрузки или перегреве система немедленно отправляет оповещение в Telegram до того, как оборудование выйдет из строя.
3. **Единая панель контроля для всех домашних устройств**:
   - На сервере развертываются агенты мониторинга домашнего роутера, NAS-хранилища, умных камер и рабочих ПК семьи. С одной ссылки родители и администратор видят здоровье всей домашней сети.
